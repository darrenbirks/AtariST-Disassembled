Blocks

Dimmed blocks have no tile for the pair they would make at the cursor.

Tiles

A tile is a pair of blocks: its own and the one to its right. Painting a block picks the tiles for the cell and its left neighbour. A pair with no tile can take over a tile no longer on the map, of the same type, if the game's sorted tile order stays the same; tile numbers the code uses directly are never taken.

Objects

Open level15.inc.

A group appears all at once when its trigger point (the diamond) comes into view; a single object (dashed) appears when it comes into view itself. The game has room for 10 bad guys at a time. The middle of a marker's bottom edge is where the object stands; the small markers are objects the game does not draw (checkpoints, the level end watchers, things the code writes into the map). Moving a start position moves the view and the player together; edit score_scroll_x and the others in the fields.
