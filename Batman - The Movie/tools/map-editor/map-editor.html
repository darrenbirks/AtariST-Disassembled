Blocks

Dimmed blocks have no tile for the pair they would make at the cursor.

Tiles

A tile is a pair of blocks: its own and the one to its right. Painting a block picks the tiles for the cell and its left neighbour. A pair with no tile can take over a tile no longer on the map, of the same type, if the game's sorted tile order stays the same; tile numbers the code uses directly are never taken.
